AiShield - AI-Powered Women's Safety Solution
Overview
AiShield is an AI-driven web application designed to enhance women's safety by providing self-defense training, safe route navigation, and AI-powered emergency assistance. By leveraging machine learning, computer vision, and IBM’s Watsonx tools, AiShield empowers women with proactive security solutions.

Key Features
🔹 Train Yourself
Provides self-defense training videos for learning techniques.
Users can practice, record their actions, and upload them for AI-based accuracy analysis.
AI & ML models deployed on IBM Watsonx.ai evaluate user movements and provide feedback.
🔹 SafeMap
Maps safe routes based on nearby public utilities like police stations and hospitals.
Routes are color-coded:
🟢 Green (Safe Route) – Near police stations, hospitals, and public areas.
🔴 Red (Unsafe Route) – Near bars, nightclubs, and isolated areas.
🔹 DefendChat AI
AI chatbot powered by IBM Watsonx Assistant for emergency assistance.
Provides real-time safety tips and emergency response guidance.
